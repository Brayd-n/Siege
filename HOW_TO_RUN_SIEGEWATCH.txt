SIEGEWATCH - HOW TO RUN THE GAME
================================

Get the game from https://github.com/Brayd-n/Siege.
You can play it from the Godot editor on Windows, macOS, or Linux, or run the
ready-made Windows executable without installing Godot.


OPTION 1: PLAY FROM THE GODOT EDITOR (WINDOWS, MACOS, OR LINUX)
---------------------------------------------------------------
1. Install Godot 4.7 (Godot 4.3 or newer should also work).
2. Get the project files from the repository:
     - On GitHub, click Code > Download ZIP, then extract the ZIP; or
     - Run: git clone https://github.com/Brayd-n/Siege.git
3. Open Godot. In the Project Manager, click Import, browse to the extracted
   or cloned Siege folder, and select project.godot. Click Import & Edit.
4. Wait for Godot to import the assets, then press F5 (or click the Play button).

The first launch may take longer while Godot imports assets and builds shaders.


OPTION 2: PLAY THE WINDOWS .EXE
-------------------------------
The executable is stored with Git LFS because it is larger than GitHub's normal
file limit. To get the actual executable, install Git and Git LFS, then run:

    git lfs install
    git clone https://github.com/Brayd-n/Siege.git
    cd Siege
    git lfs pull

Open the build folder in the cloned Siege folder and double-click Siegewatch.exe.
If the file is only a tiny text pointer, Git LFS did not download it; run
git lfs pull again inside the Siege folder. A GitHub Code > Download ZIP copy
may contain that pointer instead of the executable.

The executable is self-contained, so Godot is not needed to play it. Windows
may show a SmartScreen warning because the executable is unsigned.


IF THE GAME RUNS SLOWLY
-----------------------
- Laptops with two graphics chips may run the game on the weaker one.
  Fix: Windows Settings > System > Display > Graphics > Add desktop app,
  pick Godot (or Siegewatch.exe), click it, Options > High performance > Save.
- In the game: Settings > untick "High graphics".
- Keep a laptop plugged in.


FIRST STEPS IN THE GAME
-----------------------
- Click a map on the Campaign screen, pick a hero and a difficulty.
- Press H to place your hero for free, then recruit soldiers with 1-8 and
  left-click beside the road.
- Press Space to start the wave.
- Settings > "Unlock all levels & soldiers (demo)" opens everything at once,
  handy for showing the game to someone.


CONTROLS
--------
Camera               WASD / arrow keys to move, mouse wheel to zoom,
                     Q / E or right-drag to rotate
Recruit soldier      1-8 (or click a card), left-click to place,
                     Shift+click to keep placing
Place hero           H (or the gold HERO card)
Hero abilities       Z and X, then left-click to aim
Move hero            Select the hero, then right-click the ground
Select soldier       Left-click it
Talk / special       T / G  (with a soldier selected)
Targeting mode       Tab
Start wave           Space
Pause / speed        P / F  (buttons for 1x, 2x, 3x and Auto at the top right)
Menu                 Esc
Fullscreen           F11

All gameplay keys can be changed in Settings > Key bindings.

Debug keys (for testing): F1 +500 gold, F2-F5 spawn enemies,
F6 finish the wave, F7 +10 lives, F8 next wave.


SAVING
------
Progress (unlocks, Crowns, gear, hero mastery) saves automatically.
To stop mid-battle, open the menu with Esc and choose "Save & quit to map",
then use "Continue" on the main menu later.
